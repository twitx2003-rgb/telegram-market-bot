# Financial Broadsheet Design System

Full spec: `design.md` (repo root). Live showcase: `docs/design-system.html`.

The DNA of the world's leading financial-news sites (Bloomberg / FT / WSJ):
**editorial serif headlines** + **newspaper hierarchy** (a dominant lead story,
then graduated rows with kickers, bylines, and thin rules). Hybrid palette —
dark Bloomberg-terminal default + FT-salmon paper light theme — warm amber accent.

- Emoji: section/tab labels only, sparingly. Never in data surfaces.
- Every component works in BOTH themes (dark default + `body.light`).

## 2. Tokens — source of truth is `:root` in `build_html()`

| Token | Dark (Bloomberg) | Light (FT paper) | Use |
|---|---|---|---|
| `--bg` | `#1c1f22` | `#fff1e5` | page background |
| `--card` | `#14171a` | `#fffaf3` | panels/cards |
| `--surface` | `#0d0f11` | `#f6e7d7` | sunken: inputs, tracks, bars |
| `--border` | `rgba(255,255,255,.08)` | `rgba(51,48,46,.12)` | hairline rules |
| `--accent` | `#e0a35a` (amber) | `#b06a34` (terracotta) | links, active tab, kickers, hover |
| `--white` | `#f4f1ea` | `#33302e` (ink) | headlines, key numbers |
| `--text` | `#a8a49c` | `#4a453f` | body text |
| `--muted` | `#6c6860` | `#8a8178` | labels, meta, bylines |
| `--green` | `#34d399` | `#0a7a4f` | **data only**: up/bullish/buy |
| `--red` | `#f87171` | `#c0392b` | **data only**: down/risk/stop |
| `--gold` | `#fbbf24` | `#9a6a15` | **data only**: caution/watch |
| `--e1/--e2/--e3` | shadow ladder | softer | card elevation (data cards) |

Rules: no new hex in components. Tinted bg = rgba of same hue at .10–.14.
Amber `--accent` carries interaction; `--white`/ink carries headlines & numbers.
Color (green/red/gold) ONLY on data.

## 3. Typography — editorial serif + clean sans

- **Frank Ruhl Libre** — headlines (400/500/700/900). The classic Hebrew newspaper serif. Masthead, lead story, `.row-title`, `.news-title`, major section headings.
- **Assistant** — body, UI, buttons, kickers, labels, nav (300–700).
- **Inter** — numerals/tickers/Latin only. Always `tabular-nums`, always `dir="ltr"`.

| Level | Font | Size | Weight | Tracking |
|---|---|---|---|---|
| Masthead | Frank Ruhl Libre | clamp(2.1–3.6rem) | 900 | 0 |
| Lead headline | Frank Ruhl Libre | clamp(1.5–2.2rem) | 900 | 0 |
| Row headline | Frank Ruhl Libre | 1.2rem | 700 | 0 |
| Kicker | Assistant | .66rem | 700 | `.16em` uppercase |
| Body / dek | Assistant | .9rem | 400 | 0 |
| Byline / meta | Assistant | .72rem | 600–700 | `.02em` |
| Section label | Assistant | .62rem | 700 | `.32em` |
| Numeric-lg | Inter | 1.5rem | 800 | `-.02em` |

No fourth family. No italic on headlines.

## 4. Depth & Shape

- **News feed = flat broadsheet**: no boxes/shadows on stories — thin `--border`
  rules between rows; the lead story sits above a `2px solid var(--white)` rule.
- **Data cards** (pulse/ideas/TA/market) still use `box-shadow:var(--e1)`,
  hover → `var(--e2)` + `translateY(-3px)`.
- Radius: **8px** data cards · 6px inputs · 999px pills/chips.
- Section rhythm 2.6–3rem; container 1140px.

## 5. Component Patterns

**Masthead** — publication name in Frank Ruhl Libre, `2px solid var(--white)` rule
under it, dateline row (date · time · market-status · F&G) in tracked sans caps.

**Section label** — auto-numbered via CSS counters (`.tab-pane` resets, `.section-label::before` increments `.01`-style). Just write the label; the number is automatic.

**Lead story** (`.lead-story`) — kicker + big serif `.lead-title` + dek + byline, rule beneath. The top-ranked feed item only.

**Story row** (`.story-row`) — kicker (`.row-kicker`, accent small-caps) + serif
`.row-title` + `.byline` (source · time · links), separated by `--border` rules.
Kicker = the tag's Hebrew label (`_kicker()`); sentiment shown as a small dot.

**Active state** (tabs, filter chips) — white/ink fill, dark text:
`color:var(--card); background:var(--white)`

**Recommendation pills** — the only colored component (data): `.rec-buy` green /
`.rec-watch` gold / `.rec-wait` muted; rgba background, 999px radius.

**Levels bar** — LTR track on `--surface`; fill gradient green→white; markers:
price=white, entry=white, stop=red.

**Pulse widgets** (`.pulse-*`) — market-pulse tab: sentiment stacked bar (green/muted/red
segments), horizontal frequency bars (`.freq-*`, white/dim fills), bull/bear leaderboard
(`.lb-*`, two-column, green/red). Data colors only on sentiment/direction.

**Trade-idea cards** (`.idea-card`, `.signal-chip`, `.mention-badge`) — ticker + mention
badge, sentiment dot, monochrome signal chips, optional mini-TA line + sparkline.

**Inputs** — sunken `--surface`, bottom hairline, focus → white hairline.

## 6. RTL Rules

- Document `dir="rtl"`. LTR islands: prices, tickers, English quotes, levels bar, sparklines.
- Emphasis border on the RIGHT edge (`border-right:3px solid var(--white)`).
- `margin-left:auto` where LTR would use `margin-right:auto`.

## 7. Do / Don't

DO: shadow-lift hover · white for interaction · color only on data · numbered sections.

DON'T: brand/blue colors · card frames (borders as structure) · gradients (hero
glow exception) · fourth font family · animation beyond hover/pulse/ticker/fadein ·
color on navigation.

## 8. Data-viz

Up/down = green/red only; intensity via alpha ladder (heatmap ±2%→.45, ±1%→.25, 0→.10).
Sparklines 52×22 stroke 1.5. Confidence: 5 dots, filled=white/accent. Never truncate numbers.
