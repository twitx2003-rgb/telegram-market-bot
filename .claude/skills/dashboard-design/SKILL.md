# Graphite Design System (TURA-derived)

Full spec: `design.md` (repo root). Live showcase: `docs/design-system.html`.

## 1. Identity

Monochrome dark, TURA-derived: near-black panels floating on graphite, depth via
soft shadows (not borders), heavy tracked-out geometric display type, tiny
spaced labels, `.01` section numbering. **White is the only interactive accent.**
Color appears ONLY when it carries data meaning. RTL Hebrew.

- Emoji: section/tab labels only, sparingly. Never in data surfaces.
- Every component works in BOTH themes (dark default + `body.light`).

## 2. Tokens — source of truth is `:root` in `build_html()`

| Token | Dark | Use |
|---|---|---|
| `--bg` | `#212529` | graphite page background |
| `--card` | `#101316` | panels/cards (near-black) |
| `--surface` | `#0b0d0f` | sunken: inputs, tracks, ticker tape |
| `--border` | `rgba(255,255,255,.07)` | hairline separators — NOT card frames |
| `--white` / `--accent` | `#f4f5f7` | headlines, key numbers, ALL interactive states |
| `--text` | `#9aa3ad` | body text |
| `--muted` | `#5c6670` | labels, meta |
| `--green` | `#34d399` | **data only**: up/bullish/buy |
| `--red` | `#f87171` | **data only**: down/risk/stop |
| `--gold` | `#fbbf24` | **data only**: caution/watch/earnings |
| `--e1/--e2/--e3` | shadow ladder | resting / hover / hero elevation |

Rules: no new hex in components. Tinted bg = rgba of same hue at .10–.14.
NEVER color on nav/buttons/decoration — white handles all interaction.

## 3. Typography (Hebrew adaptation of Cera CY)

- **Rubik** — display + headings (400–900). Geometric, softly rounded — the Cera CY analogue.
- **Assistant** — body, UI, buttons (300–700).
- **Inter** — numerals/tickers/Latin only. Always `tabular-nums`, always `dir="ltr"`.

| Level | Font | Size | Weight | Tracking |
|---|---|---|---|---|
| Display (hero) | Rubik | clamp(1.9–3.2rem) | 900 | `.06em` |
| H1 | Rubik | 1.6rem | 800 | `.02em` |
| H2 (card title) | Rubik | 1.15rem | 700 | `.01em` |
| Body | Assistant | .9rem | 400 | 0 |
| Button/Tab | Assistant | .82rem | 700 | `.02em` |
| Caption/meta | Assistant | .72rem | 600 | `.04em` |
| Section label | Rubik | .62rem | 700 | `.32em` |
| Numeric-lg | Inter | 1.5rem | 800 | `-.02em` |

No fourth family. No italic.

## 4. Depth & Shape

- Hierarchy by shadow, not border: cards get `box-shadow:var(--e1)`,
  hover → `var(--e2)` + `translateY(-3px)`. `--border` is a hairline helper only.
- Radius: **8px** cards/panels · 6px inputs · 999px pills/chips · 5px badges.
- Section rhythm 2.6–3rem; card padding `1rem 1.3rem`; container 1140px.

## 5. Component Patterns

**Section label** — auto-numbered via CSS counters (`.tab-pane` resets, `.section-label::before` increments `.01`-style). Just write the label; the number is automatic.

**Active state** (tabs, filter chips) — white fill, dark text:
`color:var(--card); background:var(--white)`

**Recommendation pills** — the only colored component (data): `.rec-buy` green /
`.rec-watch` gold / `.rec-wait` muted; rgba background, 999px radius.

**Levels bar** — LTR track on `--surface`; fill gradient green→white; markers:
price=white, entry=white, stop=red.

**Inputs** — sunken `--surface`, bottom hairline, focus → white hairline.

## 6. RTL Rules

- Document `dir="rtl"`. LTR islands: prices, tickers, English quotes, levels bar, sparklines.
- Emphasis border on the RIGHT edge (`border-right:3px solid var(--white)`).
- `margin-left:auto` where LTR would use `margin-right:auto`.

## 7. Do / Don't

DO: shadow-lift hover · white for interaction · color only on data · numbered sections.

DON'T: brand/blue colors · card frames (borders as structure) · gradients (hero
glow exception) · fourth font family · animation beyond hover/pulse/ticker/fadein ·
color on navigation.

## 8. Data-viz

Up/down = green/red only; intensity via alpha ladder (heatmap ±2%→.45, ±1%→.25, 0→.10).
Sparklines 52×22 stroke 1.5. Confidence: 5 dots, filled=white/accent. Never truncate numbers.
