# Dashboard Design System

## 1. Identity

Professional fintech terminal. Dark-first, RTL Hebrew, data-dense but calm.
Bloomberg-adjacent — not consumer-app playful. The user checks this page many
times a day on phone and desktop; clarity beats decoration.

- Emoji: allowed ONLY in tab labels and section labels, sparingly. Never inside
  data surfaces (cards, tables, chips, numbers).
- Every component must work in BOTH themes (dark default + `body.light` overrides).

## 2. Design Tokens — single source of truth is `:root` in `build_html()`

| Token | Dark | Semantic use |
|---|---|---|
| `--bg` | `#080c10` | page background |
| `--surface` | `#0d1117` | nav, ticker tape, strips |
| `--card` | `#111820` | all card backgrounds |
| `--border` | `#1c2a38` | all borders, dividers |
| `--accent` | `#06b6d4` | interactive + brand ONLY (links, active tab, hover) |
| `--green` | `#10b981` | up / bullish / buy — nothing else |
| `--red` | `#f43f5e` | down / risk / stop — nothing else |
| `--gold` | `#f59e0b` | caution / watch / earnings — nothing else |
| `--purple` | `#8b5cf6` | tag accent (TECH etc.) |
| `--text` | `#94a3b8` | body text |
| `--muted` | `#475569` | secondary/meta text |
| `--white` | `#f0f6ff` | headlines, big numbers |

Rules:
- NO new hex colors in components. Tinted backgrounds = `rgba()` of the SAME hue
  at alpha .10–.15 (e.g. green pill bg = `rgba(16,185,129,.12)`).
- Documented exceptions (keep, do not spread): sparkline stroke `#22c55e`/`#ef4444`,
  heatmap alpha ladder, Fear&Greed gauge ramp — legacy data-viz ramps.

## 3. Typography

- **Heebo** — Hebrew display: headlines, card titles, tab labels. Weights 700–900.
- **Inter** — numbers, tickers, Latin text. Weights 400–800.
- Numbers ALWAYS `font-variant-numeric:tabular-nums`.
- Tickers: Inter 800, letter-spacing `.04em`, LTR.
- Scale: `.65rem` uppercase labels (letter-spacing `.28em`) / `.72–.78rem` meta /
  `.86rem` body / `1.06rem` card title / `1.4rem` stat number / `clamp()` hero.
- Max 2 font families. Never pure-white long text blocks — `--white` is for
  headlines and key numbers only.

## 4. Layout & Spacing

- Container `max-width:1140px`.
- Section rhythm: `2.6rem` between sections; `.section-label` above every block.
- Card padding `1rem 1.3rem` (content) / `.8rem 1rem` (stat).
- Radius: **14px** content cards, **10px** stat cards/chips, **5px** badges.
- Grid gaps `.8–1rem`.

## 5. Component Patterns (canonical)

**Section label**
```html
<div class="section-label">🎯 הזדמנויות טכניות</div>
```

**Stat card** — `.mkt-card`: name (muted, .72rem) → value (white, 1.4rem, tabular) →
change row (green/red + arrow).

**Content card** — `.news-card`: optional image top, `.card-top` (tag badge + meta),
title (Heebo 800), summary (`--text`), `.card-meta` footer (source · time · links).

**Badge/tag** — colored text + same-hue rgba bg + 5px radius:
```html
<span class="news-tag" style="color:var(--green);background:rgba(16,185,129,.12)">EARNINGS</span>
```

**Pill (recommendation)** — `.rec-buy` green / `.rec-watch` gold / `.rec-wait` muted;
bold, `.72rem`, radius 999px.

**Levels bar** — LTR horizontal track: support (right label in RTL page but the bar
itself is `dir="ltr"`), gradient fill to current-price marker, resistance at the far
end. Entry marker = accent; stop marker = red. Pure HTML/CSS, no JS.

## 6. RTL Rules

- Document is `dir="rtl"`. LTR islands (`dir="ltr"`): prices, tickers, English
  quotes, the levels bar, sparkline containers.
- Sentiment/emphasis border sits on the RIGHT edge (`border-right`).
- Use `margin-left:auto` where LTR layouts would use `margin-right:auto`.

## 7. Do / Don't

DO:
- Hover: `border-color:var(--accent)` + `translateY(-2px)`, transition `.2s`.
- One accent color per card — the recommendation pill OR the setup badge dominates.
- `overflow-x:auto` wrapper for anything wider than mobile viewport.

DON'T:
- New hex colors outside tokens.
- More than 2 font families or new font weights.
- Gradients (hero exception only).
- Animation beyond: ticker tape scroll, pulse dot, hover transitions.
- Nested cards (card inside card).

## 8. Data-viz Rules

- Up/down = green/red ONLY. Intensity = alpha ladder (heatmap: ±2% → .45, ±1% → .25, 0 → .10).
- Sparklines: 52×22, stroke 1.5, no fill, no axes.
- Confidence: 5 dots, filled = value, unfilled = `--border`.
- Never truncate numbers to make them fit — shrink the font or wrap the layout.
